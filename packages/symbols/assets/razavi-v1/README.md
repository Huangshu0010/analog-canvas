# Razavi v1 Symbol Assets

This directory is the source of truth for the `razavi-symbols@1` component
catalog.

The catalog currently contains 12 reviewed canonical assets (`capacitor`,
`current-source`, `diode`, `ground`, `inductor`, `nmos`, `npn`, `pmos`, `pnp`,
`port`, `resistor`, and `voltage-source`) plus provisional `nmos3` and `pmos3`
assets.
Canonical MOS assets remain electrically four-terminal; their
`textbook-3terminal` variant hides bulk presentation only.

- `catalog.json` records source VSS Master, decoder version, review state, pin
  order, palette/mapping reachability, asset path, and canonical asset hash.
- `*.symbol.json` files are normalized Symbol DSL assets. Geometry may change
  only through a reviewed migration; pin order follows the electrical review
  manifest rather than visual inference.
- The four MOS assets are generated by
  `scripts/generate-visio-mos-assets.mjs` from checked RV-6 Master IR. Their
  intrinsic geometry, transforms, 1.2/2.16 point weights, and Visio Arrow Type
  13 heads are source-derived. Only external terminal leads are adjusted along
  their own axes to land electrical anchors on the 10-unit grid.
- The reviewed high-frequency non-transistor assets (`resistor`, `capacitor`,
  `inductor`, `diode`, `ground`, `port`, `voltage-source`, and
  `current-source`) are generated by
  `scripts/generate-visio-core-analog-assets.mjs` from the same checked RV-6
  Master IR. Their independent Visio evidence is stored under
  `fixtures/visual-reference/visio-core-analog/`. The converter preserves
  supported intrinsic geometry and fails on unsupported source primitives;
  only terminal-lead endpoints may move to satisfy the electrical grid.
- `pnpm symbols:visio-core-analog` is the only public Batch A generation
  command. It atomically refreshes these assets, catalog provenance/hashes, and
  the generated TypeScript runtime adapter; `:check` verifies all four layers.
- `node` is intentionally absent as a component. Its VSS evidence is cataloged
  under `semanticPrimitives` and is consumed later by Junction presentation.
- Automatic three-terminal MOS mapping and bulk/variant selection remain
  disabled until their pin semantics and Net classification policy are
  reviewed.
- `packages/symbols/src/razavi-catalog.generated.ts` is a deterministic runtime
  adapter generated from these JSON files. Do not edit it directly.

Canonical hashes use UTF-8 JSON with LF line endings and one final newline, so
Windows checkout policy does not change asset identity.

Update and verify the adapter with:

```powershell
pnpm symbols:razavi
pnpm symbols:razavi:check
pnpm symbols:visio-mos:check
pnpm symbols:visio-mos:reference:check
pnpm symbols:visio-core-analog:check
pnpm symbols:visio-core-analog:reference:check
```
