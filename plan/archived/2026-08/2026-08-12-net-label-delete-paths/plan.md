# Make Net-label deletion address-independent

## Goal

Ensure both the Route action and the standard Delete command can remove Net
labels created by the current editor as well as imported or legacy documents
whose annotation ids do not follow the editor's generated naming convention.

Shared dependency: annotation identity and transaction semantics in

## Work

1. Replace fixed generated-id lookup with an explicit, deterministic lookup
   for labels associated with the selected Route/Net, while preferring a
   directly selected label.
2. Make an annotation selection expose an unambiguous delete action, alongside
   the existing Delete/Backspace shortcut.
3. Add a browser regression for a legacy/imported Net label whose id is not
   generated by the editor.
