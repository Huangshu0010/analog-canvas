# Archived Phase 9 Research Evidence

This directory preserves early Phase 9 trial narratives and generated
artifacts. Their original executors no longer satisfy the current project
schema, hierarchical-symbol grid, or route validation contracts, so these
files are historical evidence rather than runnable gates.

The SPICE sources remain in `netlists/` and are still covered by the current
SPICE corpus tests. The current optional research entry points are documented
under `tools/research/phase9/`.
